# Complaint Management System

A simple complaint management system built with Next.js, MongoDB, and Tailwind CSS.

## Features

- User authentication (login/register)
- Submit complaints with title, description, and optional photo
- View list of submitted complaints
- Update complaint status

## Technologies Used

- Next.js 13 (App Router)
- MongoDB (with Mongoose)
- NextAuth.js for authentication
- Tailwind CSS for styling
- Multer for file uploads

## Getting Started

### Prerequisites

- Node.js (v18 or later)
- MongoDB (local or Atlas)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/complaint-management-system.git
   cd complaint-management-system

   ```

2. Installations:
```bash
npx create-next-app@latest complaint-management-system
cd complaint-management-system
npm install mongoose
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init
npm install bcryptjs
npm install framer-motion


```
